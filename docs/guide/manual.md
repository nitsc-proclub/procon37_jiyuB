# 操作ガイド

絵を描き、その絵から絵描き歌をつくって再生する基本の流れです。画像は既存マニュアルから抜粋したもので、画面の表示は現在のアプリと異なる場合があります。

## 1. 絵を描く

キャンバスに好きな絵を描いてください。PCではマウスのドラッグ、スマートフォンでは指での操作に対応しています。

![キャンバスに猫の絵を描いた画面](../assets/manual/draw.png)

## 2. 歌をつくる

「歌をつくる！」を押し、生成が終わるまで待ちます。生成中は進捗バーが表示されます。歌の生成にはインターネット接続が必要です。保存するかを選ぶ画面が出たら、希望する選択肢を押して進みます。

![歌をつくるボタンと生成中の進捗バー](../assets/manual/generate.png)

## 3. 再生する

再生ボタンを押すと、歌声に合わせて絵を描くアニメーションが流れます。もう一度遊ぶときは「新しい歌を作る」を押してください。

![再生ボタンと絵描き歌のアニメーション・歌詞](../assets/manual/play.png)

画像の出典と加工内容は[画像の出典記録](../assets/manual/README.md)を参照してください。
