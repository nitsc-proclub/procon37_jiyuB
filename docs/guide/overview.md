# 作品コンセプトと開発の背景

超えかき歌！は、子どもが描いた絵からオリジナルの絵描き歌をつくるWebアプリです。主に4〜8歳の子どもを対象にしています。[公開版](https://cho-ekaki-uta.nitsc-proclub.workers.dev/)では、絵を描いて歌をつくる体験を試せます。

## 「また描いてみたい」と思える体験

作品のコンセプトは「表現活動の肯定」です。絵の上手さを評価するのではなく、描いた絵を歌にして返します。子どもが自分の表現を楽しみ、また描きたくなることを目指しています。

描くたびに歌が変わる楽しさや、家族や友達と一緒に聴く時間も、この作品で大切にしたいことです。自分の絵が歌になり、周りの人が喜ぶ。そんな体験を、次の表現の励みにしたいと考えています。

## 体験会を通じた改善

2026年5〜9月に、施設やイベントで計6回の体験会を開きました。延べ1,000人を超える子どもたちに体験してもらっています。特に4〜8歳の反応が良かったことから、主な対象年齢を定めました。

操作に迷う姿を見て、ボタンを大きくし、案内表示を見直しました。保護者が結果を撮影していたことから、絵と歌詞を印刷して持ち帰れる機能も加えています。生成を待つ間の演出や、歌詞と線の対応を示す表示も改善してきました。

歌への感想を集める評価機能も開発しています。現在の公開版は通常1候補を生成し、評価の中央保存は停止中です。公開版と展示版の違いは[技術概要](technical-overview.md)にまとめています。

## 絵から歌をつくる工夫

絵描き歌では、何を描いたかに加えて、描いた順序も大切です。完成画像と線の情報から歌詞を作り、一定のリズムで歌えるように楽譜へ変換します。

| 工夫 | 仕組み | 主な実装 |
| --- | --- | --- |
| 描き順を生かした作詞 | 近い線をグループにまとめ、位置・順序・時間を画像と一緒に送る | [groupStrokes](../../services/strokeGroupingService.ts)、[buildLegacyLyricsPrompt](../../services/lyricsPipeline.ts) |
| 絵描き歌に合わせた楽譜 | 歌詞のモーラ、アクセント、語の区切りから音の高さと長さを決める | [buildSingingScore](../../services/melodyService.ts)、[アクセント解析](../../services/voicevoxAccentService.ts) |
| 歌声と絵の同期 | 歌詞に対応する線を再生位置に合わせて表示する | [DrawingPlaybackCanvas](../../components/DrawingPlaybackCanvas.tsx)、[KaraokeLyricsPanel](../../components/KaraokeLyricsPanel.tsx) |
| 作品の持ち帰り | 絵と歌詞を印刷用のレイアウトに並べる | [PrintLayout](../../components/PrintLayout.tsx) |

楽譜は絵描き歌用の処理で組み立て、VOICEVOX Engineで歌声を合成します。歌詞や線との対応は絵や生成結果によって異なり、意図と異なる結果になる場合もあります。

操作は[操作ガイド](manual.md)、処理全体は[技術概要](technical-overview.md)で説明しています。
