# モバイルシーンの後続アイデア

## 歌が完成したときのページめくり演出

縦画面で生成から再生へ移るときだけ、画面全体に短いページめくりを表示するよう実装した。再生と主要な操作は演出を待たずに使え、`prefers-reduced-motion` では表示しない。一度の生成遷移につき一度だけ実行され、再生の開始・停止では再実行されない。

## リリース前の実機確認

- iOS Safari と Android Chrome で、URLバーが伸縮した状態の native audio コントロールが、safe area の内側に見え続けること。
- 縦／横回転後に、低い画面では「絵・現在歌詞・再生操作」が使えること。全歌詞は「歌詞をみる」から展開できること。
- Workers の公開ビルドで、生成完了から再生シーンへの遷移とページめくりを確認すること。Cloudflare Access 配下では、認証済みの実機セッションで確認すること。
