# 印刷専用レイアウト仕様案

## 目的

生成した絵描き歌を、A4横1枚で持ち帰れるプリントにする。
子どもがあとから見返して歌えること、紙の上の大きなイラストをなぞってもう一度描けること、歌詞と書き順の対応がわかることを重視する。

## 用紙

- サイズ: A4横
- 印刷: カラー前提
- 余白: ブラウザ印刷で切れにくいよう、紙面内に8mm前後の内側余白を持たせる
- 背景: 既存アプリに近い薄いオレンジと白を基調に、インク量を抑えた淡いドット・方眼模様を敷く
- 背景印刷: `print-color-adjust: exact` と `-webkit-print-color-adjust: exact` を指定し、PDF保存時にも背景色と模様を維持する

## 必須要素

- ロゴ
  - 既存の「超えかき歌！」ロゴを表示する
  - ロゴの下、または横にローマ字で `Cho Ekaki Uta` を表示する
  - ロゴは紙面の主役にしすぎず、タイトルと作品を邪魔しないサイズにする
- タイトル
  - `lyrics.title`
  - 紙面上部に大きく表示する
- 歌詞
  - `lyrics.lines`
  - 4行程度を想定し、大きく読みやすく表示する
  - 既存の `KaraokeLyricsPanel` に近い、白い角丸カード + オレンジ強調の見た目にする
- イラスト
  - `drawingData.imageUri` または demo-records の `input.png`
  - なぞり書きできるように、紙面内で最も大きい要素として表示する
  - 表示枠は正方形にする
  - 元の描画が小さい場合でも、印刷時は `object-fit: contain` で可能な限り大きく拡大する
- 書き順ステップ
  - `lyrics.lineStrokeMappings` と `drawingData.strokes` / `strokeGroups` を使う
  - 各歌詞行に対応する時点までの累積描画を小さな正方形サムネイルで表示する
  - 歌詞と書き順サムネイルは横並びにして、1行ずつ対応がわかるようにする
  - 余裕があるレイアウトでは、ステップ間に矢印を入れて進行がわかるようにする
- 名前欄
  - 手書きできる線だけを表示する
- 日付
  - 自動で印刷日を表示する

## 入れない要素

- 「この絵をなぞって、もう一度かいてみよう」「大きく印刷」などの説明文
- 「歌詞と書き順」「歌詞の横が、そのとき描くところ」などの見出し説明
- 生成対象のラベル
- 「ここにもう一度かいてみよう」のような大きな空白欄
- メモ欄
- 「できたもの」欄
- 音声プレイヤー風のUI
- モデル名などの技術情報

## 推奨レイアウト

### 案A: 左に大きい正方形イラスト + 右に歌詞と書き順

- 左側: なぞり用の大きな正方形イラスト
- 右側上部: タイトル、対象ラベル、日付、名前欄
- 右側中央: 歌詞行と、その行に対応する書き順サムネイルを横並びで表示
- 右側下部: 必要なら補助的な完成ステップや注記

利点:

- イラストが大きく、なぞりやすい
- 歌詞と書き順の対応が一目でわかる
- 絵描き歌らしい「この歌詞でここを描く」感が強い

### 案B: タイトル上部 + イラスト中央最大 + 歌詞下部

- 上部: タイトル、対象ラベル、日付、名前欄
- 中央: 大きなイラスト
- 下部: 歌詞と書き順ステップを横並び

利点:

- とにかくイラストを大きくできる
- 小さい絵を印刷時に大きく見せる用途に強い

## 書き順ステップの実装方針

1. `lyrics.lineStrokeMappings[index].strokeGroupIds` を読む
2. `strokeGroups` から対応する raw stroke index を集める
3. その行までに登場した stroke を累積する
4. 小さな SVG または canvas に累積 stroke を描画する
5. サムネイル下に `lyrics.lines[index]` を短めに表示する

最終行に stroke が割り当たっていない場合は、「完成」として全 stroke を表示する。

## 歌詞行数への対応

歌詞行数は固定ではないため、印刷レイアウトは行数に応じて調整する。

- 3〜4行
  - 標準サイズで表示する
  - 歌詞と書き順サムネイルを1行ずつ大きく見せる
- 5〜6行
  - 歌詞のフォントサイズ、行間、サムネイルサイズを少し下げる
  - それでも1枚に収める
- 7行以上
  - まず歌詞生成側で短くする方針を検討する
  - 印刷側では、2段組またはサムネイル縮小で収める
  - 読みにくくなる場合は、印刷前プレビューで警告を出すことも検討する

レイアウト実装では、CSS class または inline style で `lyrics.lines.length` に応じた密度モードを切り替える。

## 注意点

- 歌詞が長い場合は、行ごとにフォントサイズを少し下げて紙面内に収める
- 画像は白背景を保ち、線が薄くなりすぎないようにする
- なぞり書き用の大きいイラストは、線を少し薄くするか、通常濃度のままにするかを実機印刷で比較する
- 小さい入力絵は印刷時に拡大されるため、粗さよりも「紙面上でなぞれる大きさ」を優先する
