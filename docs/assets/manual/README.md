# マニュアル画像の出典

元資料: `マニュアル表紙以外_超えかき歌.pdf`（6ページ）。基本操作の説明に使う画面を抜粋しています。元PDFそのものはこのリポジトリに含めていません。

ページ番号はPDF内の順番を1から数えたものです。元資料の紙面に印字された番号とは異なります。

| 画像 | PDFページ（紙面番号） | 抜粋内容 | 寸法 | ファイル容量 |
| --- | --- | --- | --- | --- |
| `draw.png` | 1（2） | 手順③のPC描画画面 | 453 × 351 px | 21,620 bytes |
| `generate.png` | 2（3） | 手順④の生成ボタン、手順⑤のPC生成中画面 | 759 × 874 px | 53,918 bytes |
| `play.png` | 3（4） | 手順⑦の再生ボタン、手順⑧のPC再生中画面 | 613 × 630 px | 39,763 bytes |

加工: Popplerでページ長辺を1,500 pxに描画し、必要な画面部分を切り抜きました。生成・再生の画像は2か所の抜粋を縦に並べ、幅をそろえるため一部を拡大しました。PNGを128色に減色し、圧縮して保存しました。赤い枠と矢印は元資料にある注記です。

2026-10-09に元ページと生成画像を目視確認しました。採用範囲に個人情報・認証情報がないことを確認し、ブラウザのURL欄や資料全体を含まないよう切り抜いています。画像は元資料時点の画面例であり、現行UIを撮影したものではありません。
